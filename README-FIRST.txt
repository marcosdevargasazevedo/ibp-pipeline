IBP Pipeline Explorer V7 — Presentation-first viewer

Starts in presentation mode. Click any node for a read-only right-hand details inspector. Click Edit in the upper right to unlock the full editing toolbar. Switch back with Present. The exact V3–V6 localStorage key (ibp-pipeline-editor-v3) is unchanged; saved cards, positions and connections are preserved in the same browser and origin. Before upgrading, export a JSON layout backup from V6.

Installation: copy this folder into your existing ibp-visualizer project, npm.cmd install and npm.cmd run dev.

Pipeline metadata remains a static snapshot. Existing editor limitations on dynamic Snakemake relationships still apply.
